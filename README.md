# dashboards
Репозиторий-портфолио для хранения моих работ с данными


# Папка "monitoring"
Проект связанный с мониторингом и анализом цен поставщиков на товары
В этой папке собраны sql запросы на создание представлений, скриншоты дашбордов и также Python код в котором были собраны дашборды и использованием Streamlit и Plotly
Кстати, это отдельный проект написанный на Python: сбор, мэтчинг, аналитика с использованием ИИ. Он лежит в приватном репозитории: https://github.com/diggorpo/monitoring

# Папка "yandex_market_leman"
Проект связанный с финансовым учетом, ведением личного кабинета селлера, рекламной аналитикой на яндекс маркете

В этой папке собраны на создание представлений, скриншоты дашбордов с Yandex DataLens
Кстати, для работы с яндексом у меня есть несколько проектов:
1) ETL-проект для сбора данных с Яндекс Маркета (приватный): https://github.com/diggorpo/yandex_market_platform
2) ERP-проект на GAS для управления в том числе ЯМ (приватный): https://github.com/diggorpo/yandex_market_app_script
